Uso pessoal · Rclone + Google Drive

Backup Pessoal Rclone

Esta é a página informativa de uma integração pessoal usada para arquivar e restaurar projetos de desenvolvimento por meio do rclone e do Google Drive.

O que a integração faz?

Com a autorização da conta Google, o rclone permite transferir arquivos de backup do computador para o Google Drive e recuperá-los quando necessário. A permissão configurada é drive.file, destinada aos arquivos criados ou abertos pela aplicação.

O uso é pessoal, não é oferecido como serviço público e não exige que visitantes deste site façam login.

Privacidade e dados

O acesso ao Google Drive ocorre pela autorização OAuth do próprio usuário. Os backups não são publicados neste repositório ou no GitHub Pages. Leia a Política de Privacidade para detalhes.
